Family and Friends 3 — Spelling Lists

16 units · 2 tests per unit · phonics tests fixed at 8 words, vocabulary tests sized to the unit · 241 words, no repeats

The split. Every unit gets two tests. Test 1 is always the unit’s theme vocabulary; Test 2 is always the unit’s phonics pattern — the same sound family the student book teaches in that unit, so the spelling test reinforces the lesson rather than running beside it. Every phonics test is a fixed 8 words — the rule is the same difficulty everywhere, so the set size is too. Vocabulary tests are trimmed to fit the unit, dropping the words that are long, low-frequency, or unfair to spell at this level (grandma, Australia, crocodile, helicopter, dictionary…), so they run 6–8 words. The count on each test says how many.
  • Phonics sets are built out to eight with words that follow the same rule, drawn from the book’s word families first and then extended (e.g. Unit 3 ar: car, park, shark, star, scarf + farm, card, hard).
  • Vocabulary is single words only — phrases are reduced to their core word (have a shower → shower, brush my teeth → teeth).
  • Dropped: multi-word compounds, abbreviations (TV, P.E., MP3), and proper nouns that add no spelling rule.
  • No word appears twice in the whole book — 241 tested words, 241 unique.
  • Unit 0 is the Starter unit and has no phonics section, so its Test 2 is a short-vowel review. The months moved out to make room; run them as a separate warm-up if you want them.
